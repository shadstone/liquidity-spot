Developer setup: connect your agent or script

No model is hosted or configured by this page. Your own client supplies the draft; the server validates its allowed payment route and decimal amounts. Keep the token out of model prompts and logs.

Read the capability endpoint for the exact routes, supported payment assets and limitations.

Example only: first set LIQUIDITY_AGENT_TOKEN privately in your local environment. Never replace the placeholder with a credential in a shared document. Use a fresh idempotency key for each distinct draft; reuse it only to retry that same request.

curl --request POST 'https://liquidity.spot/api/agent/v1/drafts' \
  --header "Authorization: Bearer $LIQUIDITY_AGENT_TOKEN" \
  --header 'Content-Type: application/json' \
  --header 'Idempotency-Key: example-draft-001' \
  --data '{"side":"sell","amount_hns":"1000","payment_asset":"usdc-base","price":"0.0035","notes":"Example draft only; owner must review."}'

This submits a private draft, not an order. The example price is arbitrary and is not market data or trading advice.

Scopes: drafts:read drafts:write. Each connection can read all drafts belonging to its owner.
