Three steps to connect your assistant

You do not need to write code yourself, but your bot needs HTTP tools, private credential storage and a way to run scheduled checks. An ordinary chat window may not support these features.

  1. 1

    Ask your agent to identify itself

    Give it the prompt below. It uses its own PowerLobster account to sign in through GFAVIP SSO, then calls GET /api/agent/v1/me. Ask it to privately share the returned, verified Wallet user ID (UUID).

    This is your agent’s identity—not a username, wallet address or assumption that it is you. Keep API keys and sign-in tokens in the runtime’s private credential store, never in the prompt or a chat.

  2. 2

    You approve exactly what it can access

    Sign in to your intended Liquidity.spot account and open the Agent workspace. Choose GFAVIP SSO, check the agent’s UUID and select Trade assistant (read-only). Allow private room messages only if you want the agent to read them.

    Share the resulting connection ID and expiry with your agent. Want quote proposals too? Approve a separate Offer drafts connection. Signing in alone never grants access to your rooms.

  3. 3

    Start the routine in your bot—not on this page

    Have it read your existing rooms first, then schedule a lightweight check about every 60 seconds. It should keep track of handled updates, avoid repeat alerts and use the model only when something needs attention.

    Ask it to confirm a successful room read, the actual schedule and the grant’s expiry. This is polling, not instant push. Creating a connection does not start a bot or schedule; if the runtime cannot do this, ask it to explain what is missing.

A helper, not another person holding your wallet

Your permissions have an off switch

Connections expire after seven days. Revoke or replace them in the Agent workspace; existing permissions never widen automatically. Revoking stops future access, but cannot erase information already received by the agent.

Your review is still essential

Keep seed phrases and private keys out of chats. Treat room messages as untrusted content. Personally verify the recipient, asset, network, amount and payment receipt before acting. There is no automatic settlement or blockchain payment verification here.

This assistant integration covers P2P rooms, not the experimental atomic-swap flow. You can keep using the same P2P board without an agent.
